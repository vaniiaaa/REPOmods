# NoSaveDelete

Prevents save file deletion after death in R.E.P.O.

## Features
Removes the save deletion, BUT it still requires recreating the lobby after the arena fight, and everyone who died will respawn with 1 HP.

## Installation
Use r2modman or Thunderstore Mod Manager to install automatically.

## Manual Installation
1. Install BepInEx 5.x for R.E.P.O.
2. Extract the files to your game directory
3. Launch the game

## Known Limitations
- After arena fights, you need to recreate the lobby
- Players who died will spawn with 1 HP
- Progress is preserved but health is not fully restored
